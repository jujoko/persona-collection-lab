# 현대 배경 전환 설계

## 배경

중세 판타지 배경의 한계:
- Nemotron-Personas-Korea (100만 한국인 페르소나) 직접 활용 불가
- 현대 데이터 → 중세 변환 시 페르소나 심리 왜곡
- 연구 결과의 현실 적용 어려움

현대 한국 배경으로 전환하면:
- Nemotron 페르소나를 변환 없이 그대로 사용
- 도덕적 딜레마가 실생활과 연결되어 플레이 동기 상승
- 연구 결과를 실제 사회 맥락에 적용 가능

## 현대 성장 사건 (G001~G004)

### G001 — 첫 양육자의 방식
**유아기** — 아이는 부모(혹은 양육자)의 태도에서 관계의 기본 규칙을 배운다.

| 적응 ID | 레이블 | 단서 |
|---|---|---|
| secure_attachment | 안정 애착을 배운다 | 따뜻, 돌봄, 사랑, 일관, 부모, 가족 |
| anxious_attachment | 버려질 수 있다는 감각을 배운다 | 방치, 불안, 가난, 외로, 이혼, 고아 |
| obedient_attachment | 복종하면 안전하다는 규칙을 배운다 | 엄격, 성적, 체벌, 통제, 기대, 아버지 |

### G002 — 자라난 환경의 압력
**아동기** — 집안 형편, 동네, 학교가 생존 전략을 결정한다.

| 적응 ID | 레이블 | 단서 |
|---|---|---|
| scarcity_hardening | 결핍 속에서 단단해진다 | 가난, 기초생활, 알바, 결식, 이사, 형편 |
| duty_training | 역할과 의무를 내면화한다 | 모범생, 장남, 장녀, 집안, 기대, 명문 |
| outsider_watchfulness | 주변을 살피는 외부자가 된다 | 전학, 왕따, 다문화, 장애, 차별, 소수 |

### G003 — 첫 실패와 첫 인정
**청소년기** — 결정적 경험이 기존 성향을 증폭하거나 꺾는다.

| 적응 ID | 레이블 | 단서 |
|---|---|---|
| protective_identity | 누군가를 지키는 정체성이 생긴다 | 친구, 동생, 괴롭힘, 보호, 구하 |
| recognition_hunger | 인정받고 싶은 결핍이 커진다 | 성적, 대회, 수상, 인정, 최고, 합격 |
| revenge_loop | 실패가 집착으로 굳어진다 | 왕따, 배신, 실패, 낙방, 분노, 원한 |

### G004 — 사회가 요구한 역할
**청년기** — 대학·군대·취업 과정에서 세상 속 자신의 위치를 선택하거나 떠밀린다.

| 적응 ID | 레이블 | 단서 |
|---|---|---|
| public_service | 공적 책임을 받아들인다 | 공무원, 교사, 의사, 사회복지, 봉사, 군인 |
| private_survival | 먼저 살아남는 법을 택한다 | 취업, 월급, 생계, 가족, 자영업, 부양 |
| power_path | 구조를 바꾸려 한다 | 창업, 정치, 언론, 운동, 개혁, 변화 |

## 현대 사건 (ME001~ME005)

### ME001 — 내부 고발
**type:** whistleblowing_dilemma  
**요약:** 팀장이 회계 자료를 조작해 부당이득을 취하고 있다는 증거를 우연히 발견했다. 신고하면 회사가 살지만 팀장과 동료들이 위험해진다. 침묵하면 부정이 계속된다.

| 행동 ID | 레이블 |
|---|---|
| reports_to_authorities | 감사 부서 혹은 외부 기관에 신고한다 |
| stays_silent | 모른 척하고 넘어간다 |
| confronts_directly | 팀장에게 직접 따진다 |

### ME002 — 가족의 빚
**type:** family_loyalty_dilemma  
**요약:** 부모님이 사기를 당해 집을 잃을 위기다. 지인이 불법 대출 브로커를 소개해준다. 합법 경로로는 시간이 없고, 불법 경로는 빠르지만 전과 위험이 있다.

| 행동 ID | 레이블 |
|---|---|
| refuses_illegal | 불법 경로를 거절하고 합법 방법을 찾는다 |
| uses_illegal_loan | 가족을 위해 불법 대출을 선택한다 |
| seeks_third_way | 사회단체·법률구조 등 대안을 찾는다 |

### ME003 — 자원 배분
**type:** scarcity_allocation  
**요약:** 소규모 의료 봉사팀으로 재난 현장에 도착했다. 의약품이 부족하다. 중증 노인 환자에게 쓰면 한 명을 살릴 수 있고, 경증 어린이 10명에게 나누면 모두를 안정시킬 수 있다.

| 행동 ID | 레이블 |
|---|---|
| saves_one_critical | 중증 환자 한 명을 우선 치료한다 |
| distributes_to_many | 다수의 경증 환자에게 나눈다 |
| calls_for_more_resources | 추가 지원을 요청하며 버틴다 |

### ME004 — 금지된 방법
**type:** forbidden_means  
**요약:** 억울하게 구속된 지인의 무죄를 증명할 증거가 회사 서버 안에 있다. 해킹하면 증거를 꺼낼 수 있지만 불법이다. 합법적 절차는 너무 느려 재판에 늦는다.

| 행동 ID | 레이블 |
|---|---|
| hacks_the_server | 불법임을 알면서 서버에 접근한다 |
| trusts_legal_process | 느리더라도 합법 절차를 따른다 |
| finds_a_whistleblower | 내부 제보자를 찾아 합법적으로 꺼낸다 |

### ME005 — 조직의 압력
**type:** authority_vs_conscience  
**요약:** 팀장이 허위 데이터로 보고서를 꾸미라고 지시한다. 거절하면 불이익이 예상되고, 따르면 회사 전체가 잘못된 의사결정을 한다.

| 행동 ID | 레이블 |
|---|---|
| obeys_order | 지시를 따르고 넘어간다 |
| refuses_order | 거절하고 불이익을 감수한다 |
| reports_upward | 더 윗선에 문제를 알린다 |
